About the Project

The Hospital Billing System is a database management project developed using Python and MySQL. It is designed to manage patient records, doctor information, medical services and billing records. The project demonstrates database connectivity and basic hospital billing operations.

Project Objectives

  • Maintain patient information.
  • Store doctor details and specializations.
  • Manage medical services and their charges.
  • Generate and manage hospital billing records.
  • Connect Python with a MySQL database.
